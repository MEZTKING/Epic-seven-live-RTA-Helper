Game watcher

One watcher for the whole app: it captures the game once, works out which screen is showing and runs every reader (Gear item details, Guild War enemy name; RTA moves here next). Modules just receive what it finds, so there's no "start" button per module. Desktop app: it runs by itself in the background after you pick the game window once. Browser: it runs on this page; keep this tab open.

      Teach heroes (your own examples)

      Open any picture of the game (a saved game picture, a screenshot file, or paste one with Ctrl+V), drag a square around one round hero icon, type who it is and press Add. The app keeps that face as an example and recognises the hero from it next time: RTA pre-bans and CR bar, Guild War defense icons. Most useful for skins and heroes it keeps getting wrong. This is learning from examples (each one is compared like the official portraits), not training a neural network, so it works from the first example. Pick banners on the draft are taught on RTA → Auto → "Name the heroes on this picture".

      Other examples (kept separately)

        Where things are kept: everything stays on this device in the app's own storage (saved game pictures in its picture store; examples as small 32×32 faces). Developer → "Collect screenshots automatically" in the desktop app saves PNG files to Pictures\Epic 7 Engine\<date>.

        How it works: four layers

        1. Capture: a live picture of the game window.
        2. Screen detector: recognises which game screen is showing (taught once, below). Readers only run on their own screen.
        3. Readers: RTA draft, drafting help, postbans, opponent name, CR bar, Victory/Defeat · Guild War enemy name · Gear item details.
        4. Overlay: draws what the readers found next to the game's own UI: suggestions by the draft slot, enemy speeds, Guild War dots, gear verdicts.

        Everything only reads the screen. Nothing ever clicks or types into the game.

        Screens taught on this device

        Teach a screen from its module while the game watcher is watching (Gear → "This is the item screen", Guild War → "This is the enemy screen", RTA → Auto). 2–3 examples each work best.

        Desktop app

        Needed for the overlay on top of the game, and to skip the "choose a window to share" prompt each session.

        1. Install Node.js (LTS).
        2. In the project folder: cd desktop, npm install, npm start.
        3. Or build one .exe: npm run dist.

        Shortcuts: Ctrl+Shift+O overlay on/off · Ctrl+Shift+E main window. Details in desktop/README.md.
